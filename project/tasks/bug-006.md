## Report

User clarified that hiding the 3D monitor after zoom is not enough. The intended flow is that the screen appears to zoom in, and then the log files, file viewer, and ECHO chat UI appear inside that enlarged computer screen.

## Expected Behavior

- Clicking the computer should feel like entering the monitor.
- The Hermes OS UI should be rendered as the contents of the zoomed terminal screen.
- File explorer, log viewer, resource HUD, and ECHO chat should feel embedded inside that screen surface.

## Actual Behavior

The previous fix removed the mismatched 3D backdrop in gameplay, but the Hermes OS still appeared as a flat full-page web layout rather than as the visible result of a monitor zoom-in.

## Fix

- Wrapped the entire gameplay UI in `terminal-screen-surface`.
- Added a terminal-screen zoom animation from a smaller monitor plane into a full viewport screen.
- Added monitor screen treatment: scanlines, inner bezel, terminal glow, and screen-surface background.
- Kept the 3D control room for pre-terminal context, while making the gameplay UI read as the monitor contents after zoom.
