## Report

User reported that the layout does not line up during the screen zoom-in transition after starting the game.

## Expected Behavior

The PLAY-to-opening transition should keep the menu/monitor composition centered while the camera zooms toward the 3D control-room terminal.

## Actual Behavior

The transition used simultaneous CSS scaling on the 3D backdrop and the DOM menu monitor, which could make the layers drift against each other during zoom-in.

## Fix

- Removed CSS scale transforms from the fixed 3D backdrop during menu/transition phases so the R3F camera owns the zoom motion.
- Changed the menu launch animation from scale-out to fade/blur with a small vertical lift.
- Forced the backdrop canvas to fill the fixed scene container height to avoid viewport mismatch during transition.
