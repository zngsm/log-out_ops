## Report

The terminal screen appeared as a generic full-screen surface rather than expanding from the visible monitor plane.

## Expected Behavior

- The Hermes OS screen should feel as if it starts from the monitor surface and expands into the viewport.
- The transition should preserve monitor framing and not feel like a flat route change.

## Actual Behavior

The previous `terminal-screen-surface` zoom animation scaled from a broad page surface, which still weakened the physical monitor-to-DOM connection.

## Fix

- Adjusted `terminal-screen-surface` transform origin to match the computer hotspot/monitor area.
- Added `clip-path` stages so the surface begins as a smaller monitor-like rectangle and opens into full viewport.
- Extended the animation timing to make the monitor-entry transition more legible.
