## Report

User reported that after zooming into the computer, the physical monitor layout behind the UI and the internal Hermes OS screen do not align at all.

## Expected Behavior

After the camera zooms into the computer, the Hermes OS should become the full monitor screen. The player should no longer see a mismatched physical 3D monitor frame behind the DOM terminal UI.

## Actual Behavior

The gameplay UI rendered over the 3D scene while the physical monitor/backdrop remained visible, causing the terminal layout and background monitor plane to appear as two misaligned layers.

## Fix

- Hide the 3D scene backdrop in `phase-gameplay`.
- Add a dedicated Hermes OS terminal background for gameplay.
- Keep the 3D control-room scene for room-first start/transition/opening contexts only.
