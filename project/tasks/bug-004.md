## Report

User clarified that the start should not feel like a flat PLAY menu. The intended opening composition is a spaceship control room with a computer visible in the scene. The player should understand they are suddenly trapped by the AI, then click the computer so the camera zooms into the computer screen and the game starts.

## Expected Behavior

- First screen shows the spaceship/control-room environment and computer as the main object.
- AI lockdown/trapped state is communicated before terminal entry.
- The computer itself is the interaction target.
- Clicking the computer triggers zoom-in toward the terminal and starts gameplay.

## Actual Behavior

The previous start screen used a large `LOGOUT ISOLATION` overlay card with PLAY/QUIT buttons, which made the experience read like a conventional menu and covered too much of the 3D room/computer composition.

## Fix

- Replaced the large menu card with a room-first start overlay.
- Added ECHO lockdown broadcast copy over the 3D control-room scene.
- Added a centered `CLICK COMPUTER` hotspot as the interaction target.
- Changed click flow from PLAY-to-opening-card into terminal zoom transition and immediate gameplay entry.
- Removed menu/transition blur from the 3D backdrop so the room and computer are visible on the first frame.
