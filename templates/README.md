# Templates Guide

이 폴더는 두 영역으로만 나뉜다.

- `human-input/`
  - 사람이 PM agent에게 넘기기 전에 직접 작성하는 입력 문서 템플릿
- `agent-output/`
  - PM / DEV / QA agent가 작업하면서 생성하는 결과 문서 템플릿

사람이 처음 채워야 하는 것은 `human-input/` 아래 5개뿐이다.

## Human Input Templates

- `human-input/project_brief.template.md`
- `human-input/gameplay_spec.template.md`
- `human-input/scene_flow.template.md`
- `human-input/direction_and_content.template.md`
- `human-input/asset_plan.template.md`

## Agent Output Templates

- `agent-output/pm_analysis.template.md`
- `agent-output/pm_questions.template.md`
- `agent-output/mvp_scope.template.md`
- `agent-output/task_board.template.md`
- `agent-output/timeline.template.md`
- `agent-output/task.template.md`
- `agent-output/qa_test_plan.template.md`
- `agent-output/qa_result.template.md`
- `agent-output/change_request.template.md`
